# 客服服务SLA（测试文档）

## 响应时效
- 在线客服首响：30 秒内。
- 人工工单首响：2 小时内。
- 升级投诉首响：1 小时内。

## 处理时效
- 常规咨询：当天闭环。
- 退款/补发争议：1-2 个工作日。
- 质量故障判定：2-3 个工作日。

## 服务分级
- P1（高风险投诉）：涉及人身安全、舆情风险、法律风险，需立即升级主管。
- P2（中风险投诉）：重复投诉、超时未解决、金额争议较大。
- P3（一般咨询）：普通售后与使用问题。

## 质检与回访
- P1/P2 工单需记录完整处理链路。
- 关闭后 24 小时内进行一次满意度回访。

## 升级规则
- 用户明确要求“投诉升级”时，客服不可拒绝，应创建升级单并标注原因。
