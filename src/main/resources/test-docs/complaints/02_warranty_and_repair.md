# 保修与维修说明（测试文档）

## 保修期限
- 手机/平板主机：12 个月有限保修。
- 配件（充电器、数据线）：6 个月有限保修。
- 电池容量衰减属于自然损耗，不在无条件保修范围内。

## 免费保修条件
- 在保修期内且存在非人为故障。
- 设备无私拆、无进液、无严重外观破损。
- 可提供有效购买凭证或订单号。

## 非保修情形
- 跌落、挤压、进液、私自刷机导致的损坏。
- 超出保修期的故障。
- 使用非官方配件造成的故障。

## 维修时效
- 常规故障：3-5 个工作日。
- 主板/屏幕等重度维修：7-15 个工作日。

## 备机与补偿
- 若维修超时超过 15 个工作日，可申请备机或延保补偿。
